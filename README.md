## Story and Source Order 
The featured story covers a pop-style research article on meeting daily recommended fiber requirements. The story is 766 words in total. Sources are fully cited in APA format in the documentation container per assignments request. (The images used are all open domain, but for the purpose of maintaining a good record, a screenshot of the image license information is in the images folder.)

## Flow and Layout Foundation
The page relies on a grid format ranging for a 2 column grid for wide viewports and a 1 column grid for small viewports. There is no fixed height set for any elements or images. All have a height of "auto" to remain responsive. 

## Positioned Relationships
The issue-badge element primarily is an absolute positioned object that falls back on a relative position for smaller viewports. The aside element has a sticky position that scrolls with the article. The featured image has a controlled overlap with the figcaption on top of the image. 

## Layer System
The theme from previous projects had design tokens brought over and applied to maintain theme. No links are obscured or blocked from the pointer. 

## Shapes and fallback
The border-radius property is used as a fallback for the clip-path on the image in section-two. The text to the left of the curve around the image due to the shape-outside property on the image. The composition plan outlines the fallback and technique used on each element that is positioned, layered, clipped, rounded, or
shape-wrapped.
