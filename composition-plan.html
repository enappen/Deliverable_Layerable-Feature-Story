Complete one row for every positioned, layered, clipped, rounded, or shape-wrapped element. Duplicate rows as needed.

Element Content purpose Normal-flow baseline Chosen technique and why Containing block / stacking context Fallback or disengagement Required test
div (.article-container) To place the aside and article in one container to ensure the aside minds the boundaries of the article (placing them on the same layer). This also acts as a parent container for the aside element to stop it when the story ends. Block The positioned div is static to stay in the normal document flow. The element follows a grid layout that creates 2 columns for viewports larger than 52rem and 1 column for smaller viewports. When the larger viewport is in effect, the aside and article elements align on 1 row. For smaller viewports, the aside stacks on top of the article. The div element is disengaged when the end of the element is reached. Replace
aside (.story-guide) The aside is used as a navigation guide for the featured story. Block The sticky position is used so the aside navigation can travel downward with the user as they read the document to remain an available usable resource. The containing block is the div container (.article-container) in column 1 with a column width of 14rem. A margin-left of 4rem is applied to accommodate the blockquote element. The sticky element is disengaged when the user scrolls to the end of the div (.article-container). Replace
article The article contains the sections, images, and shapes pertaining to the featured story. Block A static flow position is used so the user may progress reading through the story without any unexpected behaviors and allow for the contents to remain in the normal flow of the document. The containing block is the div container (.article-container) in column 2. No width is set to allow the column to automatically take up the remaining space. The sticky element is disengaged when the user scrolls to the end of the div (.article-container). Replace
Figcaption The figcaption provides additional context to the images purpose and its connection to the featured story. Inline The relative position is used to adjust the caption position from it's original location to move it up over the image. The containing block is a figure (.feature-figure) and is after the image element in the contained figure. The figcaption element is disengaged at the end of the image. On a smaller viewport the text wraps to the next line approximately (the top of the figcaption is approximately 4rem from the top). This creates a controlled overlap. Replace
Image (.shape-portrait) The image, with class shape-portrait, is helpful for providing a visual to various types of fiber that connect to the section 2 text in the featured story. Block The image, with the class shape-portrait, is clipped using the clip-path property with the value circle(7.6rem). Relative units are used to maintain consistent clipping mask. The image has a float property with value inline-start to have the image anchor to the left of text. The shape-outside creates a rounded boundary box for the text to fall along. The shape-margin of 0.5rem add to the newly defined boundary box. The containing block is the section element, with class section-two. The stacking context for smaller viewports proceeds in the order of heading, image, then text. The element is disengaged at the end of the section element. Replace
